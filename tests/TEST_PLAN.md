# 验证计划

使用 Python 标准库 unittest。重点检查影响可信度和安全边界的行为，而非页面内部实现细节。

- 上海时区日期窗口与起止边界；非法日期及超过 14 天窗口。
- HF 推荐旧论文的日期依据；arXiv 版本合并并保留多源链接。
- OpenReview 公开投稿不冒称录用；会议论文集首次运行仅建立基线。
- 来源失败与成功空集可区分；标签噪声和跨模态噪声对应能匹配画像。
- 模型恶意或错误 JSON、未知候选 ID、伪造题名或链接不污染事实。
- HTTP CSRF、Host、Origin、内容类型、路径穿越、非公开来源 URL 校验。
- SQLite 重启后恢复；Unicode 与特殊字符导出。
- 离线全来源 fixture 与伪 Codex 子进程完整运行；明确标记样例。
- 限时真实网络与 Codex 结构化输出检查；浏览器桌面与手机布局及关键操作。
